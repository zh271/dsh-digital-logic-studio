# 第 2 章 组合逻辑（参考）

> 助教查阅用。组合逻辑的输出只取决于当前输入，电路中没有反馈，也没有记忆元件。
> 芯片引脚名称按教材常用写法给出，括号内为常见别名。所有引脚的有效电平、编号以所用手册为准，遇到不确定时请学生对照器件手册。
> 涉及 3 变量以上的化简、降维后的函数值，仍需调用 `dlogic_bool` / `dlogic_verify`。

## 1. 组合逻辑电路的分析

分析的目标是由电路图得到输出表达式，并说明它的逻辑功能。常用四种方法，可以组合使用：

1. **逐级推导法**：从输入端开始，逐级写出每个门的输出（中间变量），最后得到输出表达式。
2. **列表达式法**：把各级中间变量代入，得到最终的输出表达式，然后化简并说明功能。化简可以用公式法或工具（`dlogic_bool` 的 `minimize`）。
3. **列真值表法**：对每一种输入组合，计算输出，列出真值表，据此归纳逻辑功能（如判断一致、判断奇偶、加法、比较大小等）。
4. **波形分析法**：给定输入波形，逐段求各级、最终输出的波形。用于观察传输延迟造成的时序关系和竞争冒险。

**分析示例（讲解用）**：$Y = \overline{\overline{AB}\cdot\overline{BC}\cdot\overline{AC}}$。
- 逐级推导：三个与非门输出分别为 $\overline{AB}$、$\overline{BC}$、$\overline{AC}$，再经一个与非门，得 $Y = AB + BC + AC$。
- 功能：只要两个或两个以上输入为 1，输出为 1，即三人多数表决器。

## 2. 竞争冒险

### 2.1 产生原因

门都有传输延迟。同一个信号经过不同路径到达汇合点的时间不同，若此时输出本应保持不变，却可能出现瞬间的错误尖峰（毛刺）。

- **静态 1 型险象**：输出本应保持 1，却出现 0 毛刺。
- **静态 0 型险象**：输出本应保持 0，却出现 1 毛刺。
- **动态险象**：输出本应翻转一次，却翻转多次。

产生条件：输入变化（单个变量变化最常见）且输出应当保持稳定的时刻。

### 2.2 代数法判断

- **与或式**：若在某组其他变量取值下，$F$ 的表达式（不经化简）可化为 $A + \overline{A}$，且没有其他项恒为 1，则存在静态 1 型险象。
  - 例：$F = AB + \overline{A}C$，当 $B=C=1$ 时 $F = A + \overline{A}$，存在静态 1 型险象。
- **或与式**：若在某组取值下，$F$ 可化为 $A\cdot\overline{A}$，且没有其他项恒为 0，则存在静态 0 型险象。
  - 例：$F = (A+B)(\overline{A}+C)$，当 $B=C=0$ 时 $F = A\overline{A}$，存在静态 0 型险象。
- 注意：代数法依据的是表达式的写法。冗余项可以消除险象。例如 $F = AB + \overline{A}C + BC$，在 $B=C=1$ 时 $BC$ 项恒为 1，输出不会出现毛刺。

### 2.3 卡诺图法判断

- **静态 1 型险象**：卡诺图中两个相邻的 1 格不被同一个圈圈住（两个圈相切），则存在静态 1 型险象。
- **静态 0 型险象**：两个相邻的 0 格不被同一个圈圈住，则存在静态 0 型险象。
- 例：$F = AB + \overline{A}C$ 的 1 格 $m_3 = \overline{A}BC$ 与 $m_7 = ABC$ 相邻（只有 $A$ 变化），但 $m_3$ 在圈 $\overline{A}C$ 中、$m_7$ 在圈 $AB$ 中，二者不在同一个圈里，存在险象。增加圈 $BC$ 即可把它们圈在一起。

### 2.4 消除方法

1. **增加冗余项**：加入一个圈把相切处圈住（如上例加入 $BC$）。冗余项不改变逻辑功能，但需要增加门。
2. **选通脉冲（选通/使能）**：只在输出稳定之后，才用选通信号（如时钟或使能端）把输出打开，使毛刺不被采样。
3. **输出端并联滤波电容**：吸收输出端的窄尖峰。缺点是会使输出的上升、下降沿变慢。

**讲解要点**：先判断是否存在险象，再选择消除方法。若输出接在时钟触发器上，只要在时钟有效沿之前稳定，险象通常不会影响结果。

## 3. 组合逻辑电路的设计

设计步骤：

1. **逻辑抽象**：确定输入、输出变量，规定各变量 1 和 0 的含义。
2. **列真值表**：包括约束项和任意项（见第 4 节）。
3. **写表达式并化简**：用公式法、卡诺图，或工具 `dlogic_bool`（`minimize`，`dontCares` 填入无关项）。
4. **变换表达式形式**：按现有器件选择与非、或非、与或非形式，或直接用 MUX / 译码器实现（见第 5 节）。
5. **画逻辑图或写接线表**。
6. **检查**：用 `dlogic_verify` 与原真值表比对，并检查竞争冒险（第 2 节）。

## 4. 无关项（约束项与任意项）在设计中的使用

- 约束项：输入组合不可能出现，如 8421 码的伪码（1010～1111），输出无要求。
- 任意项：输入组合可能出现，但该情况下输出可以是 0 或 1，由设计者选择。
- 使用原则：化简时把它们当作 1 或 0，以使表达式最简；不能用来凑出与原真值表冲突的结果。
- 工具输入：`dlogic_bool` 与 `dlogic_verify` 的 `dontCares` 参数。`dlogic_verify` 比对时，无关项不计入错误。

## 5. 门级等价变换

### 5.1 摩根定理与通用门

- 与非门和或非门都是通用门：仅用其中一种，可以实现任意逻辑函数。
- 反相器可由任一输入端连在一起的与非门（或或非门）实现，即 $\overline{A} = \overline{AA}$。
- 摩根定理的门级意义：同一个与门可以画成“输入端加反相的或非门”。

### 5.2 二级与非-与非形式

- 由与或式（SOP）转换：先化简为最简与或式，然后对每个乘积项取一次非，再对总和取一次非。
- 示例：$F = AB + C$ 可写成 $F = \overline{\overline{AB}\cdot\overline{C}}$。第一级：乘积项 $AB$ 用一个与非门；单变量项 $C$ 取非用一个反相器（或与非门接成反相器）。第二级：一个与非门。

### 5.3 二级或非-或非形式

- 由或与式（POS）转换：每个和项用一个或非门，再对结果用一个或非门。
- 示例：$F = (A+B)(C+D)$ 可写成 $F = \overline{\overline{A+B} + \overline{C+D}}$。

### 5.4 与或非形式（AOI）

- 由 $\overline{F}$ 的最简与或式求出，再取反：若 $\overline{F} = \sum(\text{乘积项})$，则 $F = \overline{\sum(\text{乘积项})}$。
- 示例：$F = AB + C$，$\overline{F} = \overline{A}\,\overline{C} + \overline{B}\,\overline{C}$，于是 $F = \overline{\overline{A}\,\overline{C} + \overline{B}\,\overline{C}}$。验证：$(A+C)(B+C) = AB + C$。
- 与或非门是一个器件，含若干个与门和一个或非门。

### 5.5 讲解要点

- 与非-与非形式对应与或式，或非-或非形式对应或与式。学生常常混淆这一对应关系。
- 每次变换后都要用 `dlogic_bool` 的 `gate_form` 或 `dlogic_verify` 检查。

## 6. 数据选择器（MUX）与 74LS151

### 6.1 原理

- 数据选择器在地址码控制下，从多路数据中选择一路输出。
- $2^n$ 选 1 的选择器有 $n$ 个地址输入，输出为 $Y = \sum_i m_i D_i$，其中 $m_i$ 是以地址码为变量的最小项，$D_i$ 为数据输入。

> 各芯片的功能表、引脚与有效电平见 `03-msi-74chips.md`（此处不再重复）。

### 6.4 用 MUX 实现组合函数（降维法）

思路：函数有 $n$ 个变量时，用 $2^k$ 选 1 选择器，取 $k$ 个变量作地址，其余 $n-k$ 个变量接入数据端。

步骤：
1. 选定作为地址的变量（通常取前面的变量，以便接线）。
2. 对每一种地址组合，把函数表达为剩余变量的函数。结果只可能是 $0$、$1$、$D$ 或 $\overline{D}$（$D$ 为剩余变量）。
3. 把这些结果依次接到数据端 $D_i$。

示例：$F(A,B,C,D) = BD + \overline{B}\,\overline{D}$（即 $B\odot D$）。选 $A_2 = A$，$A_1 = B$，$A_0 = C$ 为地址，$D$ 接数据。

| $ABC$ | $F$ 与 $D$ 的关系 | 数据端取值 |
|---|---|---|
| 000 | $B=0$：$F=\overline{D}$ | $D_0 = \overline{D}$ |
| 001 | $B=0$：$F=\overline{D}$ | $D_1 = \overline{D}$ |
| 010 | $B=1$：$F=D$ | $D_2 = D$ |
| 011 | $B=1$：$F=D$ | $D_3 = D$ |
| 100 | $B=0$：$F=\overline{D}$ | $D_4 = \overline{D}$ |
| 101 | $B=0$：$F=\overline{D}$ | $D_5 = \overline{D}$ |
| 110 | $B=1$：$F=D$ | $D_6 = D$ |
| 111 | $B=1$：$F=D$ | $D_7 = D$ |

- 本例中函数不依赖 $A$、$C$，它们只是作为地址；也可以把 $B$ 作地址，仅用 2 选 1 实现。讲解时指出这一点，说明地址的选取不唯一。
- 数据端取值用 `dlogic_comb`（尚未上线）或手工推导后，请学生用 `dlogic_verify` 检查。当前可用的核对方法：把接线结果逐组写成表达式，再与原函数比对。

## 9. 数据分配器

- 一个输入、多个输出，由地址选择输出的路径。可以理解为数据选择器的逆过程。
- 常用 138（使能端作数据端）或 139 实现，输出为低有效。
- 用于数据分路、多路存储器选片、显示器的位选等场合。
