# 第 5 章 可编程逻辑器件与 EDA 设计流程（参考）

> 助教查阅用。本文讲可编程逻辑器件（PLD）的分类、PAL 与 GAL 的输出结构、CPLD 与 FPGA 的区别、FPGA 的基本资源、SRAM 配置与掉电丢失、在系统编程（ISP），以及 EDA 设计流程与仿真。
> PLA、PAL、GAL 的与或阵列结构、点阵读法与 LUT 实现方法见 `05-memory.md`，本文只引用，不重复。
> 器件的具体型号、规模、速度、引脚编号等参数一律以器件手册为准，本文不列。遇到不确定的细节，请学生对照手册或课本。

## 0. 使用约定

- **PLD**（Programmable Logic Device）：由用户通过编程决定逻辑功能的集成电路。与固定功能的 74 系列器件不同，同一片器件可以实现不同电路。
- **编程方式**：熔丝或反熔丝一次编程；EPROM、EEPROM、Flash 可擦除重写；SRAM 上电后装载配置。
- **易失与非易失**：断电后配置数据是否保留。这是区分器件类型的重要依据。

## 1. 可编程逻辑器件的分类

| 器件 | 阵列结构 | 编程方式 | 掉电后配置 | 主要用途 |
|---|---|---|---|---|
| PROM | 与阵列固定（译码），或阵列可编程 | 熔丝或反熔丝，一次性 | 保留 | 查找表式存储，实现组合逻辑（见 05） |
| PLA | 与、或阵列均可编程 | 一次性或可擦除 | 视工艺而定 | 小规模组合逻辑，共享乘积项 |
| PAL | 与阵列可编程，或阵列固定 | 一次性或可擦除 | 视工艺而定 | 中小规模组合逻辑 |
| GAL | 与阵列可编程，输出经 OLMC 配置 | 电可擦除，可反复编程 | 保留 | 替代 PAL，可实现组合或时序输出 |
| CPLD | 多个逻辑块，块间由全局互连矩阵连接 | 多为 EEPROM 或 Flash，可在系统编程 | 保留 | 控制逻辑、接口逻辑，延时可预测 |
| FPGA | 大量 CLB（逻辑块）与布线资源 | 多为 SRAM 工艺，上电加载 | 丢失（SRAM 型） | 大规模数字系统、原型验证 |

**要点**

- PROM、PLA、PAL 属于早期的简单 PLD，规模小，现在较少单独使用，但其结构是理解 GAL、CPLD 的基础。
- 从 PAL 到 GAL 再到 CPLD，规模逐步增大，输出结构逐步灵活。
- 从 CPLD 到 FPGA，结构从"乘积项"转向"查找表加布线"，适合的设计也随之不同。

## 2. PAL 与 GAL

### 2.1 PAL 的结构回顾

PAL 的与阵列可编程，或阵列固定。每个输出的乘积项数量由芯片决定，各输出的乘积项不能共用（详见 05 的第 5 节）。

### 2.2 GAL 与输出逻辑宏单元（OLMC）

GAL 在 PAL 结构的基础上增加了**输出逻辑宏单元**（OLMC，Output Logic Macro Cell）。OLMC 的基本作用如下：

- **配置输出方式**：通过编程选择输出为组合输出（可带反相），或经寄存器输出（时序输出）。
- **反馈**：输出可以反馈到与阵列的输入，使时序电路的状态得以保存。
- **三态控制**：输出端可由编程决定为三态或常通。

GAL 的 OLMC 类型较多，具体的模式编码、各型号的宏单元数量与配置位，本课程省略，遇到时查手册。

**要点**

- GAL 的与阵列仍然可编程，或阵列固定，因此每个输出的乘积项数仍有限制。
- GAL 用电擦除工艺，可反复编程，这是它替代 PAL 的主要原因之一。
- 讲解时可以强调：GAL 的 OLMC 让同一器件既能做组合逻辑，也能做简单的时序逻辑。

## 3. CPLD 与 FPGA 的结构区别

| 比较项 | CPLD | FPGA |
|---|---|---|
| 基本结构 | 若干逻辑块（内含多个宏单元），块间由全局互连矩阵连接 | 大量 CLB 阵列，分布式布线通道连接 |
| 逻辑实现 | 乘积项（与或阵列）为主 | 查找表（LUT）为主，加触发器 |
| 布线 | 集中式，互连路径较固定 | 分布式，布线灵活，路径长度不一 |
| 延时 | 可预测，与布线关系较小 | 与布线关系大，需布局布线后分析 |
| 配置存储 | 多为非易失（EEPROM 或 Flash） | 多为 SRAM，掉电丢失 |
| 规模 | 中小规模 | 大规模 |
| 典型用途 | 控制逻辑、地址译码、接口转换 | 复杂数字系统、数字信号处理、原型验证 |

**要点**

- 两者都是可编程，但 CPLD 的延时较容易估计，FPGA 的资源更多、更灵活。
- 选择时，控制逻辑、对延时要求严格的简单电路，常用 CPLD；规模较大的系统常用 FPGA。

## 4. FPGA 的基本资源

FPGA 由以下几类资源组成。

**(1) 可组态逻辑块（CLB，Configurable Logic Block）**

CLB 是 FPGA 实现逻辑的基本单元，内含若干 LUT 与触发器，以及相应的进位与控制电路。具体的 CLB 内部数量以器件手册为准。

**(2) 查找表（LUT，Look-Up Table）**

LUT 的工作方式见 05 的第 6 节：$k$ 输入的 LUT 用 $2^k$ 位 SRAM 存放真值表，输入作为地址，读出的位即为输出。改变 SRAM 中的内容，即可实现不同函数。

**(3) 触发器（FF）**

CLB 内的触发器用于时序逻辑。LUT 的输出可以直接输出，也可以经过触发器再输出，由配置决定。

**(4) 布线资源**

布线资源由可编程互连线与可编程开关（多为 SRAM 控制的开关）组成，把 CLB、IOB 等连接成所需电路。布线资源占用芯片面积较大，布线结果决定信号延时。

**(5) 输入输出块（IOB，Input Output Block）**

IOB 是芯片引脚与内部逻辑之间的接口，可配置为输入、输出、双向，并可设置电平标准、上拉或驱动能力等。具体电平标准的种类以器件手册为准。

**要点**

- 讲解时可以把 FPGA 比作"一个由大量小型查找表和触发器组成的可编程网格，外围是引脚，中间靠布线连接"。
- LUT 的输入数量（如 4 输入或 6 输入）因器件而异，具体以手册为准。

## 5. 基于 SRAM 的配置与掉电丢失

多数 FPGA 采用 SRAM 工艺，其配置数据（包括 LUT 的真值表、布线开关状态、触发器的初始设置等）保存在 SRAM 中。

- **上电加载**：每次上电时，配置数据（比特流文件）需从外部存储器（如专用配置芯片或主机）加载到 SRAM 中，芯片才能正常工作。
- **掉电丢失**：断电后 SRAM 中的数据丢失，下次上电必须重新加载。
- **可反复配置**：不需要擦除器件，改变比特流即可重新配置，方便调试。

**与 CPLD 的区别**：多数 CPLD 的配置保存在非易失存储器中，掉电后配置保留，上电即可工作，无需加载。

**注意**

- 存在非易失的 Flash 型 FPGA，它掉电后配置保留，但本章以 SRAM 型为主。
- 设计完成后，若要长期使用，通常需要外接配置存储器，使每次上电自动加载。

## 6. ISP（在系统可编程）【选学】

**在系统可编程**（ISP，In-System Programmable）指器件焊接在电路板上后，即可通过接口进行编程，不需要从板上取下器件放入专用编程器。

- 常用的编程接口是 JTAG（IEEE 1149.1 标准）。通过下载电缆，计算机即可把配置数据写入器件。
- ISP 的优点是便于调试与升级，缩短开发周期。

**选学内容**：ispLSI 系列（Lattice 公司）与 EPM7128（Altera 公司 MAX7000 系列的 CPLD）是早期采用在系统编程的典型器件。学习时只需了解它们属于 CPLD 结构，并支持在系统编程，其内部宏单元、逻辑阵列块与全局布线区的细节可略去。

**注意**：不同厂商的 ISP 实现与编程接口不同，具体的编程步骤以开发软件与器件手册为准。

## 7. EDA 设计流程

使用 EDA（电子设计自动化）工具设计 PLD 或 FPGA，通常经过以下步骤。

| 步骤 | 内容 | 主要产物 |
|---|---|---|
| 1. 设计输入 | 用原理图或硬件描述语言（如 Verilog、VHDL）描述电路 | 设计文件 |
| 2. 功能仿真 | 不考虑器件延时，检验逻辑功能是否正确 | 仿真波形 |
| 3. 综合 | 把设计翻译为由基本逻辑单元组成的网表，并做优化 | 网表 |
| 4. 布局布线 | 把网表映射到器件的具体资源，并连接布线 | 布局布线结果，延时文件 |
| 5. 时序仿真 | 加入布局布线后的延时信息，检验时序是否满足要求 | 仿真波形 |
| 6. 编程下载 | 生成配置文件（比特流），通过下载电缆写入器件 | 配置文件，器件工作 |

**说明**

- 第 1 步到第 6 步并不总是一次完成。若时序仿真或下载后发现问题，需返回设计输入或综合阶段修改。
- 功能仿真可以在综合前（对源代码）进行，也可以在综合后（对网表）进行，两者都不计入器件延时。
- 原理图输入适合小规模电路；规模较大时，多用硬件描述语言。

## 8. 功能仿真与时序仿真的区别

| 比较项 | 功能仿真 | 时序仿真 |
|---|---|---|
| 目的 | 检验逻辑功能是否正确 | 检验时序是否满足要求 |
| 是否考虑延时 | 不考虑器件延时（零延时或单位延时） | 考虑布局布线后提取的实际延时 |
| 能发现的问题 | 逻辑错误、状态转换错误、功能缺陷 | 建立时间与保持时间不满足、毛刺与竞争冒险引起的错误 |
| 所处阶段 | 设计输入后，综合前后均可 | 布局布线之后 |

**要点**

- 功能仿真通过，并不说明电路能在器件上正确工作。时序仿真才能反映器件中的实际延时。
- 综合后、布局布线前的仿真仍是功能仿真，不是时序仿真，容易混淆，需要明确。

## 9. 讲解要点（给助教）

- 先用表格对比 PROM、PAL、GAL、CPLD、FPGA 的阵列与易失性，再讲各自的特点。
- 讲 GAL 时，先复习 PAL 的固定或阵列，再引出 OLMC，强调它"决定输出是组合还是寄存"。
- CPLD 与 FPGA 的区别是本章难点，建议以"乘积项还是查找表""延时是否可预测""配置是否掉电丢失"三点讲解。
- SRAM 配置的掉电丢失要结合上电加载过程讲，学生容易误以为 FPGA 的程序"写入即永久保存"。
- EDA 流程用一张流程图贯穿，再逐步标出每一步的产物，避免学生只记步骤名称。
- ISP 与 EPM7128、ispLSI 的细节为选学，课堂上只需点到为止。

## 10. 常见易错点

- 把 PAL 与 GAL 都当作"或阵列可编程"：PAL 与 GAL 的或阵列都是固定的，可编程的是与阵列。
- 认为 GAL 的 OLMC 只能做组合输出：OLMC 可配置为寄存器输出，并可反馈。
- 认为 CPLD 与 FPGA 的配置都会掉电丢失：多数 CPLD 掉电后配置保留，多数 SRAM 型 FPGA 不保留。
- 认为"可编程"就是"可以随时修改"：一次性编程的 PROM 与熔丝器件只能编程一次，修改需更换器件。
- 认为 LUT 的输入数量固定为 4：不同器件的 LUT 输入数不同，以手册为准。
- 把 FPGA 的布线资源当作无代价：布线决定信号延时，布线结果不同，时序结果也不同。
- 功能仿真通过即认为电路可以正确工作：必须再做时序仿真，检查建立时间与保持时间。
- 把综合后的仿真当作时序仿真：综合后、布局布线前的仿真仍不考虑器件延时。
- 认为设计完成后下载即永久保存（对 SRAM 型 FPGA）：每次上电都需要重新加载配置。
- 在 EDA 流程中跳过功能仿真直接下载：功能错误会延误到硬件调试阶段，排查困难。
