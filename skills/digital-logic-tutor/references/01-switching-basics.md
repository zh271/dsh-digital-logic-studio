# 第 1 章 开关理论基础（参考）

> 助教查阅用。知识点 id 以 `dlogic_knowledge` 的查询结果为准；本文只确认 `k1.5.2` = 1.5.2 用卡诺图简化逻辑函数。
> 凡涉及 3 变量以上的化简、进制换算的具体数值，必须调用工具，本文中的数值只用于讲解原理。

## 1. 数字信号与数字波形

- **模拟量**：在时间和幅度上连续变化（如温度、声音）。**数字量**：只取有限个离散值，电路中用两种电平分别表示 0 和 1，称为二值逻辑。
- **数字波形**：横轴为时间，纵轴为电平。描述数字波形常用以下参数：
  - 周期 $T$，频率 $f = 1/T$；
  - 脉冲宽度 $t_W$（高电平持续时间）；
  - 占空比 $q = t_W / T$。
- 逻辑关系既可以用真值表描述，也可以用波形描述。分析组合电路的波形时，要逐段画出各输入组合下的输出。

## 2. 数制与转换

### 2.1 进位计数制

- $N$ 进制数 $(d_{n-1}\cdots d_1 d_0 . d_{-1}\cdots d_{-m})_N$ 的值为 $\sum_{i=-m}^{n-1} d_i \times N^i$，称为按权展开。
- 常用记法：二进制 B，八进制 O（或 Q），十进制 D，十六进制 H。十六进制的数码为 0～9、A～F。

### 2.2 转换方法

| 方向 | 方法 | 注意 |
|---|---|---|
| 任意进制 → 十进制 | 按权展开求和 | 小数部分的权为负幂 |
| 十进制 → 任意进制（整数） | 除基取余 | 余数**从下往上**读（先得到的是低位） |
| 十进制 → 任意进制（小数） | 乘基取整 | 整数部分**从上往下**读（先得到的是高位）；可能除不尽，按要求的精度截止 |
| 二进制 ↔ 八进制 / 十六进制 | 以小数点为界分组：八进制每 3 位一组，十六进制每 4 位一组 | 整数部分**左侧**补 0，小数部分**右侧**补 0 |

**示例（讲解用，正式数值以工具为准）**

- $27_D \to$ 二进制：$27 \div 2 = 13$ 余 1；$13 \div 2 = 6$ 余 1；$6 \div 2 = 3$ 余 0；$3 \div 2 = 1$ 余 1；$1 \div 2 = 0$ 余 1。从下往上读得 $11011_B$。
- $0.8125_D \to$ 二进制：$0.8125 \times 2 = 1.625$ 取 1；$0.625 \times 2 = 1.25$ 取 1；$0.25 \times 2 = 0.5$ 取 0；$0.5 \times 2 = 1$ 取 1。从上往下读得 $0.1101_B$。
- $10110.011_B \to$ 八进制：整数 $10110$ 左补 0 为 $010\;110$，得 $26_O$；小数 $011$ 得 $3_O$，结果 $26.3_O$。
- $10110.011_B \to$ 十六进制：整数 $10110$ 左补 0 为 $0001\;0110$，得 $16_H$；小数 $0110$ 右补 0 后为 $0110$，得 $.6_H$，结果 $16.6_H$。

## 3. 二进制编码

### 3.1 BCD 码（二-十进制码）

| 十进制 | 8421 码（有权） | 2421 码（有权，自补） | 5421 码（有权，非自补） | 余 3 码（无权，自补） |
|---|---|---|---|---|
| 0 | 0000 | 0000 | 0000 | 0011 |
| 1 | 0001 | 0001 | 0001 | 0100 |
| 2 | 0010 | 0010 | 0010 | 0101 |
| 3 | 0011 | 0011 | 0011 | 0110 |
| 4 | 0100 | 0100 | 0100 | 0111 |
| 5 | 0101 | 1011 | 1000 | 1000 |
| 6 | 0110 | 1100 | 1001 | 1001 |
| 7 | 0111 | 1101 | 1010 | 1010 |
| 8 | 1000 | 1110 | 1011 | 1011 |
| 9 | 1001 | 1111 | 1100 | 1100 |

- 有权码：每一位有固定权值，如 2421 码的权为 2、4、2、1。
- **自补码**：某数码的每一位取反后，恰好是其 9 的补数（$x$ 与 $9-x$）的编码。例如 2421 码中 $1=0001$，取反得 $1110$，即 8；余 3 码中 $3=0110$，取反得 $1001$，即 6。
- 余 3 码 = 8421 码 + 0011，常用于 BCD 加法的修正（见第 2 章 74LS283 的应用）。
- 8421 码中 1010～1111 为伪码，不允许出现。在设计中它们常作为**约束项**（见第 5 节）。

### 3.2 格雷码

- 相邻两个编码只有一位不同。常用于避免计数、测量过程中的多位同时跳变。
- 设 $n$ 位二进制码 $B_{n-1}\cdots B_0$，格雷码 $G_{n-1}\cdots G_0$：
  - 二进制 → 格雷码：$G_{n-1} = B_{n-1}$（最高位不变），$G_i = B_{i+1} \oplus B_i$（$i < n-1$）。
  - 格雷码 → 二进制：$B_{n-1} = G_{n-1}$，$B_i = B_{i+1} \oplus G_i$（自高位向低位逐位推出）。
- 三位对照（讲解用）：

  | 二进制 | 格雷码 | 二进制 | 格雷码 |
  |---|---|---|---|
  | 000 | 000 | 100 | 110 |
  | 001 | 001 | 101 | 111 |
  | 010 | 011 | 110 | 101 |
  | 011 | 010 | 111 | 100 |

### 3.3 奇偶校验码

- 在信息位后加一位校验位，使整个码组中 1 的个数为奇数（奇校验）或偶数（偶校验）。
- 示例：信息位 $1011001$ 中有 4 个 1。偶校验时校验位为 0，码组 $10110010$ 中 1 的个数为 4（偶）；奇校验时校验位为 1，码组 $10110011$ 中 1 的个数为 5（奇）。
- 能发现奇数位（1 位或 3 位）错误，不能发现偶数位错误，也不能确定出错位置（不能纠错）。

## 4. 逻辑运算与门符号

| 运算 | 表达式 | 符号 | 真值表（$AB$ = 00, 01, 10, 11 时的输出） |
|---|---|---|---|
| 与 | $F = A \cdot B$ | & | 0 0 0 1 |
| 或 | $F = A + B$ | ≥1 | 0 1 1 1 |
| 非 | $F = \overline{A}$ | 1 加小圈 | — |
| 与非 | $F = \overline{AB}$ | & 加小圈 | 1 1 1 0 |
| 或非 | $F = \overline{A+B}$ | ≥1 加小圈 | 1 0 0 0 |
| 异或 | $F = A\oplus B = A\overline{B} + \overline{A}B$ | =1 | 0 1 1 0 |
| 同或 | $F = A\odot B = AB + \overline{A}\,\overline{B} = \overline{A\oplus B}$ | =1 加小圈 | 1 0 0 1 |

- 符号采用国标画法。学生的教材或手册中也常见美式符号（如与门为 D 形），含义相同。
- 异或的特点：两输入不同时输出 1，可用于判断是否相等、奇偶。

## 5. 正逻辑、负逻辑、三态门与 OC 门

### 5.1 正逻辑与负逻辑

- **正逻辑**：高电平表示 1，低电平表示 0。**负逻辑**：低电平表示 1，高电平表示 0。
- 同一个电路，在正逻辑下是与门，在负逻辑下就是或门。电路本身不变，逻辑功能随约定而变。
- 课程默认采用正逻辑，除非题目明确给出负逻辑约定。

### 5.2 三态门

- 输出有三种状态：0、1 和**高阻态（Z）**。使能端 EN 有效时输出为 0 或 1；无效时输出端相当于断开。
- 用途：多个门的输出挂在同一根总线上，任一时刻只能有一个门使能，否则会发生总线冲突（两个输出直接对抗）。
- 使能端有高电平有效和低电平有效两种，题目中须看清。

### 5.3 OC 门（集电极开路门，CMOS 中称漏极开路 OD 门）

- 输出级没有有源上拉管，使用时必须外接上拉电阻 $R_L$ 与电源。
- **线与**：多个 OC 门的输出直接并接到同一根线上，只用一个公共上拉电阻，总输出为各输出的与：$Y = Y_1 \cdot Y_2 = \overline{AB}\cdot\overline{CD}$。线与不是一个门，而是连线的逻辑关系。
- OC 门还可用于驱动较大负载（如继电器、指示灯）。
- 常见错误：忘记接上拉电阻，导致输出高电平不确定。

## 6. 布尔代数

### 6.1 基本定律

| 名称 | 公式 |
|---|---|
| 0-1 律 | $A + 0 = A$，$A \cdot 1 = A$，$A + 1 = 1$，$A \cdot 0 = 0$ |
| 互补律 | $A + \overline{A} = 1$，$A\overline{A} = 0$ |
| 重叠律 | $A + A = A$，$A \cdot A = A$ |
| 还原律 | $\overline{\overline{A}} = A$ |
| 交换律 | $A + B = B + A$，$AB = BA$ |
| 结合律 | $(A+B)+C = A+(B+C)$，$(AB)C = A(BC)$ |
| 分配律 | $A(B+C) = AB + AC$；$A + BC = (A+B)(A+C)$ |
| 吸收律 | $A + AB = A$，$A(A+B) = A$ |
| 吸收律（扩展） | $A + \overline{A}B = A + B$，$A(\overline{A}+B) = AB$ |
| 摩根定理 | $\overline{AB} = \overline{A} + \overline{B}$，$\overline{A+B} = \overline{A}\,\overline{B}$；多变量同理，如 $\overline{ABC} = \overline{A}+\overline{B}+\overline{C}$ |
| 包含律（冗余定理） | $AB + \overline{A}C + BC = AB + \overline{A}C$；对偶式 $(A+B)(\overline{A}+C)(B+C) = (A+B)(\overline{A}+C)$ |

- 第一个分配律要与普通代数对照：$A + BC = (A+B)(A+C)$ 在普通代数中不成立，是布尔代数特有的。
- 包含律中多出的 $BC$ 项是冗余项：无论 $B=C=1$ 时 $AB$ 与 $\overline{A}C$ 中哪一项起作用，$BC$ 都不改变结果。这一性质在第 2 章消除竞争冒险中用到。

### 6.2 三个规则

**代入规则。** 等式中任一变量用一个逻辑函数代替（所有出现处都要替换），等式仍成立。例如由摩根定理，把 $B$ 换成 $B+C$，得 $\overline{A(B+C)} = \overline{A} + \overline{B}\,\overline{C}$。

**反演规则**（求反函数 $\overline{F}$）：
1. 运算符：$\cdot$ 与 $+$ 互换；
2. 常量：$0$ 与 $1$ 互换；
3. 变量：原变量与反变量互换（只针对单个变量上的非号）；
4. 运算优先级保持不变，必要时加括号。原式中不属于单个变量的非号（即覆盖多个变量的非号）保持原样，但其内部同样要按 1～3 变换。

示例：
- $F = A\overline{B} + C$，则 $\overline{F} = (\overline{A} + B)\,\overline{C}$。
- $F = \overline{AB} + C$，则 $\overline{F} = \overline{\overline{A}+\overline{B}}\;\overline{C} = AB\overline{C}$。覆盖 $AB$ 的非号保留，其内部 $AB$ 变为 $\overline{A}+\overline{B}$。

常见错误：
- 忘记运算优先级。$F = A + BC$，$\overline{F} = \overline{A}(\overline{B}+\overline{C})$，不能写成 $\overline{A}\,\overline{B} + \overline{C}$。
- 把覆盖多个变量的非号拆开或去掉。
- 对变量取反时漏掉反变量。

**对偶规则**（求对偶式 $F^D$）：
1. 运算符：$\cdot$ 与 $+$ 互换；
2. 常量：$0$ 与 $1$ 互换；
3. 变量**不变**（原变量仍是原变量，反变量仍是反变量）；
4. 运算优先级保持不变；覆盖多个变量的非号保留，其内部同样互换运算符。

- 示例：$F = A(B+C)$，则 $F^D = A + BC$。
- 关系：若 $F = G$ 成立，则 $F^D = G^D$ 也成立。另有关系 $\overline{F}(A,B,\dots) = F^D(\overline{A},\overline{B},\dots)$，即反函数等于对偶式中所有变量取反。验证：$F = A(B+C)$ 时 $\overline{F} = \overline{A} + \overline{B}\,\overline{C}$，而 $F^D(\overline{A},\overline{B},\overline{C}) = \overline{A} + \overline{B}\,\overline{C}$。
- 常见错误：把对偶当成求反函数，忘记对偶不改变变量。

### 6.3 公式法化简

常用方法：
- **并项法**：利用 $A + \overline{A} = 1$ 合并。例如 $A\overline{B} + AB = A$。
- **吸收法**：利用 $A + AB = A$ 吸收多余项。
- **消去法**：利用 $A + \overline{A}B = A + B$ 去掉多余的因子。
- **配项法**：为了继续化简，人为添加一项 $X + \overline{X} = 1$ 或冗余项，再合并。

示例：$F = AB + A\overline{B}C + \overline{A}B$
- $AB + \overline{A}B = B$（并项），于是 $F = B + A\overline{B}C$；
- 由消去法 $B + \overline{B}(AC) = B + AC$，得 $F = B + AC$。

公式法的局限：对变量较多的函数，凭观察难以保证得到最简式。3 变量以上的化简应使用卡诺图或工具。

## 7. 最小项与最大项

### 7.1 定义（$n$ 变量）

- 最小项 $m_i$：$n$ 个变量全部出现一次的乘积项。取 1 的变量写原变量，取 0 的变量写反变量。变量顺序按 `variables`，**第一个变量为最高位**。
  - 例：三变量 $A,B,C$ 时，$m_5$ 对应二进制 $101$，故 $m_5 = A\overline{B}C$。
- 最大项 $M_i$：$n$ 个变量全部出现一次的和项。取 0 的变量写原变量，取 1 的变量写反变量。
  - 例：$M_5 = \overline{A} + B + \overline{C}$。

### 7.2 性质

- $m_i$ 与 $M_i$ 互补：$\overline{m_i} = M_i$，$m_i = \overline{M_i}$。
- 每组输入中只有一个最小项为 1；每组输入中只有一个最大项为 0。
- 任意两个不同最小项之积为 0；任意两个不同最大项之和为 1。
- 标准式：
  - 最小项之和（SOP 标准式）：$F = \sum m(\ldots)$；
  - 最大项之积（POS 标准式）：$F = \prod M(\ldots)$。
  - 同一函数的两种标准式互补编号：$F = \sum m(i_1,\ldots) = \prod M(\text{其余编号})$。

示例：$F(A,B,C) = \sum m(1,3,5,7) = C$，又 $F = \prod M(0,2,4,6)$。

## 8. 卡诺图

### 8.1 结构

- 把真值表重排成一个方格图，每个格子对应一个最小项。相邻格子的编号只差一个变量（格雷码排列）。
- **相邻定义**：只有一个变量取值不同的两个格子相邻。除了直接相邻的格子，**首尾边缘也相邻**（左右边、上下边卷绕相接），四角的四个格子也相邻。
- 常用布局（以工具返回的 `rowVars`、`colVars`、`rowCodes`、`colCodes` 为准）：
  - 2 变量：2×2。
  - 3 变量：1 行 × 8 列，或 2 行 × 4 列。常见写法是行为 $A$，列为 $BC$（顺序 00、01、11、10）。
  - 4 变量：4×4，行为 $AB$，列为 $CD$，行列都按格雷码排列。
  - 5 变量：两个 4×4 平面，由 $A$（第一个变量）区分。对应位置相同的格子在两个平面中也相邻。画法（并排或叠放）按教材为准，工具返回 `planes` 与 `planeVar` 指明平面。

### 8.2 圈组规则

1. 圈的格子数必须是 $2^k$（1、2、4、8、16）。
2. 圈要尽量大，但每个圈只能是矩形（或正方形）。
3. 圈的个数尽量少。
4. **每个圈至少包含一个未被其他圈圈过的 1 格**，否则该圈是多余的。
5. 所有 1 格都必须被圈到（至少一次）。
6. 相邻格可以被多个圈重复覆盖，但不能圈入 0 格。

**由圈写乘积项：** 圈内取值不变的变量保留，变化的变量消去；不变的值为 1 写原变量，为 0 写反变量。

- 例：圈中的格子位于 $B=1$、$D=1$ 处，且 $A$、$C$ 都变化，得乘积项 $BD$。

**圈 0 格得到 POS：** 圈组对象为 0 格，圈内取值不变的变量：取 0 写原变量，取 1 写反变量，各项做和后相乘。

### 8.3 任意项（无关项）

- **约束项**：输入组合不可能出现（如 8421 码中的伪码 1010～1111），该组合的输出取 0 或 1 都可以。
- **任意项**：输入组合可能出现，但题目不关心其输出。
- 两者在卡诺图中都标 $\times$（或 X），工具输入时用 `dontCares` 表示。
- 使用原则：可以把 X 当作 1 来扩大圈，也可以当作 0 不圈；**不能只圈 X 而不包含任何 1**。X 是否使用以化简结果最简为准。

### 8.4 化简结果不唯一

- 同一函数可能有多个等价的最简解（如"市松"式排列）。工具会返回全部等价的最简解，按 $(\text{项数}, \text{文字数})$ 代价排序。讲解时可以列出所有解，并说明它们等价。

### 8.5 易错点

- 圈的格子数不是 2 的幂（如圈 3 格、6 格）。
- 圈对角线格子（它们不相邻）。
- 漏掉首尾卷绕的相邻关系，导致圈变小或多圈。
- 把 X 当作 0 或 1 固定使用，造成与约束不符。
- 5 变量时忘记跨平面相邻。
- 圈中混入 0 格。

## 9. 集成电路的使用特性

### 9.1 类型

- **TTL 电路**（双极型）：74 标准系列、74LS 低功耗肖特基系列。电源电压 5 V。
- **CMOS 电路**（单极型 MOS）：4000 系列、74HC 系列；74HCT 系列输入电平与 TTL 兼容。

### 9.2 主要参数（具体数值以器件手册为准，下面是常见的典型量级）

| 参数 | TTL（如 74LS） | CMOS（如 74HC） |
|---|---|---|
| 电源电压 | 5 V（±5%） | 4000 系列宽范围；74HC 为 2～6 V |
| 输出高电平 $V_{OH}$ | 最小约 2.4 V | 接近 $V_{DD}$ |
| 输出低电平 $V_{OL}$ | 最大约 0.4 V | 接近 0 V |
| 输入高电平 $V_{IH}$ | 最小 2.0 V | 约 $0.7V_{DD}$ |
| 输入低电平 $V_{IL}$ | 最大 0.8 V | 约 $0.3V_{DD}$ |
| 静态功耗 | 较大 | 很小 |
| 输入电流 | 较大（输入为低电平时要拉出电流） | 极小（输入阻抗很高） |
| 工作频率与功耗 | 功耗与频率关系较小 | 动态功耗随频率升高而增加 |

- **噪声容限**：高电平噪声容限 $V_{NH} = V_{OH(\min)} - V_{IH(\min)}$；低电平噪声容限 $V_{NL} = V_{IL(\max)} - V_{OL(\max)}$。TTL 的典型值约为 0.4 V。
- **扇出系数** $N_O$：一个门能驱动同类门的最多个数。取高、低两种电平下的较小值：
  $N_O = \min\!\left(\dfrac{I_{OH(\max)}}{I_{IH(\max)}},\ \dfrac{I_{OL(\max)}}{I_{IL(\max)}}\right)$。
- **传输延迟** $t_{pd}$：输入跳变到输出跳变之间的时间，常取 $t_{pd} = \dfrac{t_{PHL} + t_{PLH}}{2}$。
- **功耗**：CMOS 的动态功耗近似为 $P \approx C_{pd} V_{DD}^2 f$，其中 $f$ 为工作频率。

### 9.3 多余输入端的处理

- **与门、与非门**：多余输入端接高电平（接 $V_{CC}$，或通过电阻接高）。TTL 可悬空，但易受干扰，不推荐。
- **或门、或非门**：多余输入端接低电平（接地）。
- CMOS 输入端不能悬空，否则会因静电或干扰导致功耗增大甚至损坏，必须接确定的电平。
- 与门多余输入端也可与有用输入并联使用，但会增加前级负载，降低速度，且要确认前级驱动能力足够。

## 10. 讲解要点（给助教）

- 先区分“数字量”与“模拟量”，再引入二值逻辑。
- 进制转换要强调“除基取余逆序读，乘基取整顺序读”。
- 布尔代数的三个规则是高频考点，反演的运算优先级问题是最常见的错误。
- 卡诺图化简要让学生自己圈，再用工具核对。工具给出的圈组是讲解依据，不是要学生背的答案。
- 涉及具体芯片的参数，以手册为准，并提醒学生核对。
