# 第 3 章 中规模集成组合器件（参考）

> 助教查阅用。本文列出 74LS138、139、148、151、153、85、283、280 的功能、引脚的有效电平与别名。
> 引脚名以国标符号为准（低电平有效的名字带上划线，如 $\overline{S_2}$），别名是教材或手册中的其他写法。
> 芯片的具体引脚编号以所用手册为准，本文不列编号。遇到不确定的细节，请学生对照器件手册。
> 函数实现的降维、与非式、接线表等结果，以计算结果为准；本文只提供器件本身的知识。

## 0. 使用约定

- **有效电平**：引脚起作用时的电平。高电平有效的引脚，有效时为 1；低电平有效的引脚，有效时为 0。
- **地址与选择端**：多位地址中，$A_2$ 为高位，$A_0$ 为低位。教材也常写作 $C$、$B$、$A$（$C$ 为高位）。
- **使能与选通**：使能端无效时，器件输出的状态由手册规定（译码器输出全无效，选择器输出为 0）。
- 芯片的引脚写法以国标为主，别名用括号标出。

## 1. 74LS138（3 线-8 线译码器）

**引脚**

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $A_2$、$A_1$、$A_0$ | $C$、$B$、$A$ | 高电平（地址） | $A_2$ 为高位 |
| $S_1$ | $E_1$、$G_1$ | 高电平有效 | 使能端 |
| $\overline{S_2}$、$\overline{S_3}$ | $\overline{E_{2A}}$、$\overline{E_{2B}}$ | 低电平有效 | 使能端 |
| $\overline{Y_0}\sim\overline{Y_7}$ | | 低电平有效 | 输出 |

**功能**

- 使能有效的条件：$S_1 = 1$，且 $\overline{S_2} = \overline{S_3} = 0$。
- 使能有效时，地址 $i$ 对应的输出 $\overline{Y_i} = 0$，其余输出为 1。
- 使能无效时，全部输出为 1。
- 工作时 $\overline{Y_i} = \overline{m_i}$（$m_i$ 为地址的最小项）。

**注意**：$S_1$ 为高电平有效，不要写成低电平有效的 $\overline{S_1}$。

**用 138 实现 3 变量函数（与非形式）**

- $F = \sum m_i$ 时，把 $m_i$ 对应的低有效输出 $\overline{Y_i}$ 接入一个与非门，与非门输出即为 $F$。
- 与非门的输入端数等于最小项的个数。
- 示例：$F(A,B,C) = \sum m(1,2,4,7)$，与非门接 $\overline{Y_1}$、$\overline{Y_2}$、$\overline{Y_4}$、$\overline{Y_7}$，地址 $A_2 = A$，$A_1 = B$，$A_0 = C$，$S_1 = 1$，$\overline{S_2} = \overline{S_3} = 0$。

**用 138 作数据分配器**：把数据接入一个使能端（如 $S_1$ 或 $\overline{S_2}$），地址接 $A_2A_1A_0$。选中的输出随数据反相（低有效）。

## 2. 74LS139（双 2 线-4 线译码器）

**引脚**（两个译码器结构相同，下面以第 1 路为例）

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $1\overline{S}$ | $1\overline{E}$ | 低电平有效 | 使能端 |
| $1B$、$1A$ | | 高电平（地址） | $1B$ 为高位，$1A$ 为低位 |
| $1\overline{Y_0}\sim1\overline{Y_3}$ | | 低电平有效 | 输出 |

第 2 路的引脚为 $2\overline{S}$、$2B$、$2A$、$2\overline{Y_0}\sim2\overline{Y_3}$。

**功能**

- $\overline{S} = 0$ 时译码器工作，地址 $i$ 对应的输出为 0，其余为 1。
- $\overline{S} = 1$ 时全部输出为 1。
- 两路互相独立，可分别用于两个函数（每路最多 2 个变量）。

**用 139 实现 2 变量函数**：与非门接入对应的低有效输出，方法与 138 相同。

## 3. 74LS148（8 线-3 线优先编码器）

**引脚**

| 国标名 | 有效电平 | 说明 |
|---|---|---|
| $\overline{I_0}\sim\overline{I_7}$ | 低电平有效 | 输入，$I_7$ 优先级最高 |
| $\overline{EI}$ | 低电平有效 | 输入使能 |
| $\overline{Y_2}$、$\overline{Y_1}$、$\overline{Y_0}$ | 低电平有效 | 编码输出（编码的反码） |
| $\overline{GS}$ | 低电平有效 | 优先编码器的选通输出，有输入有效时为 0 |
| $\overline{EO}$ | 低电平有效 | 使能输出，用于扩展 |

**功能**

| $\overline{EI}$ | 输入情况 | $\overline{Y_2}\,\overline{Y_1}\,\overline{Y_0}$ | $\overline{GS}$ | $\overline{EO}$ |
|---|---|---|---|---|
| 1 | 任意 | 111 | 1 | 1 |
| 0 | 全部无效 | 111 | 1 | 0 |
| 0 | 有输入有效 | 优先级最高的有效输入编码的反码 | 0 | 1 |

**扩展**：高位片的 $\overline{EO}$ 接低位片的 $\overline{EI}$。高位片有输入时禁止低位片。

**讲解要点**：优先编码器与普通编码器不同。前者允许多个输入同时有效，只对优先级最高的一个编码。

## 4. 74LS151（8 选 1 数据选择器）

**引脚**

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $D_0\sim D_7$ | | 高电平 | 数据输入 |
| $A_2$、$A_1$、$A_0$ | | 高电平（地址） | $A_2$ 为高位 |
| $\overline{S}$ | $\overline{E}$ | 低电平有效 | 选通端 |
| $Y$ | | 高电平 | 输出 |
| $\overline{W}$ | $\overline{Y}$ | 高电平 | 与 $Y$ 互补的输出（手册写法不同） |

**功能**

- $\overline{S} = 0$ 时，$Y = D_i$，$i$ 为地址的数值（$A_2A_1A_0$）。
- $\overline{S} = 1$ 时，$Y = 0$。
- 表达式：$Y = \sum_i D_i\, m_i(A_2A_1A_0)$。

**用 151 实现函数（降维法）**

- 把函数的变量分为选择变量（接地址端）与数据变量。选择变量通常取低位变量，数据端取值由其余变量决定。
- 对每个地址 $i$，把函数展开，得到 $D_i$ 的取值：常数 0 或 1，或数据变量 $X$、其反变量 $\overline{X}$，或需要外加门的表达式。
- 若函数有无关项，无关项可取 0 或 1，以使 $D_i$ 最简。

## 5. 74LS153（双 4 选 1 数据选择器）

**引脚**（两路结构相同，下面以第 1 路为例）

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $1\overline{S}$ | $1\overline{E}$ | 低电平有效 | 选通端 |
| $B$、$A$ | | 高电平（选择） | 两路共用；$B$ 为高位，$A$ 为低位 |
| $1C_0\sim1C_3$ | | 高电平 | 数据输入 |
| $1Y$ | | 高电平 | 输出 |

第 2 路的引脚为 $2\overline{S}$、$2C_0\sim2C_3$、$2Y$。

**功能**：$\overline{S} = 0$ 时，$1Y = 1C_{i}$，$i = 2B + A$。$\overline{S} = 1$ 时，$1Y = 0$。
**降维**：用 153 时，选择变量为 2 个，每路的数据端取值由其余变量决定，方法同 151。

## 6. 74LS85（4 位数值比较器）

**引脚**

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $A_3\sim A_0$、$B_3\sim B_0$ | | 高电平 | 比较的两个 4 位数，$A_3$、$B_3$ 为高位 |
| $I_{A>B}$、$I_{A<B}$、$I_{A=B}$ | $I(A>B)$ 等 | 高电平有效 | 级联输入 |
| $F_{A>B}$、$F_{A<B}$、$F_{A=B}$ | $F(A>B)$ 等 | 高电平有效 | 比较输出 |

**功能**

- 比较规则：从最高位开始，第一对不相等的位决定大小；全部相等时，结果由级联输入决定。
- 单片使用：$I_{A>B} = 0$，$I_{A<B} = 0$，$I_{A=B} = 1$。
- 级联：低位片的 $F$ 输出接高位片的 $I$ 输入。最低位片的级联输入按单片的规则接线。总输出取最高位片的 $F$。

## 7. 74LS283（4 位二进制全加器）

**引脚**

| 国标名 | 别名 | 有效电平 | 说明 |
|---|---|---|---|
| $A_1\sim A_4$、$B_1\sim B_4$ | | 高电平 | 两个加数，$A_1$、$B_1$ 为最低位 |
| $C_0$ | $C_{in}$ | 高电平 | 低位进位输入 |
| $\Sigma_1\sim\Sigma_4$ | | 高电平 | 和，$\Sigma_1$ 为最低位 |
| $C_4$ | $C_{out}$ | 高电平 | 进位输出 |

数位编号以所用手册为准。

**功能**：$\Sigma + 16C_4 = A + B + C_0$。

- 全加器基本方程：$S = A\oplus B\oplus C_i$，$C_o = AB + (A\oplus B)C_i$。
- 超前进位：各位的进位由并行逻辑直接得到，不依次传递。

**8421 码加法（BCD 加法）**

两个 8421 码数相加，若和大于 9 或有进位，需要修正（加 6，即 0110）。

- 第一片做 $A + B + C_0$，得到和 $C_4\Sigma_4\Sigma_3\Sigma_2\Sigma_1$。
- 修正信号：$K = C_4 + \Sigma_4\Sigma_3 + \Sigma_4\Sigma_2$（和为 10～19 或有进位时 $K = 1$）。
- 第二片做 $\Sigma + 0110\cdot K$，即 $B_2$、$B_3$ 接 $K$，其余 $B$ 端与 $C_0$ 接 0。第二片的和为一位 8421 码的个位，$K$ 为十位进位。

**应用示例：8421 码转余 3 码**：余 3 码 = 8421 码 + 0011。用 283 的 $A$ 接 8421 码，$B$ 接 0011，$C_0 = 0$，和即为余 3 码。

## 8. 74LS280（9 位奇偶产生/校验器）

**引脚**

| 国标名 | 有效电平 | 说明 |
|---|---|---|
| $A\sim I$ | 高电平 | 9 个输入 |
| $\Sigma_E$ | 高电平有效 | 偶校验输出：输入中 1 的个数为偶数时为 1 |
| $\Sigma_O$ | 高电平有效 | 奇校验输出：输入中 1 的个数为奇数时为 1 |

**功能**：$\Sigma_E$ 与 $\Sigma_O$ 互补。

**用法**

- 校验：发送方送出“8 位数据 + 偶校验位”共 9 位，接收方用 280 检查。无错误时 $\Sigma_E = 1$。
- 产生：8 位数据接 $A\sim H$，$I$ 接 0。偶校验位取 $\Sigma_O$，奇校验位取 $\Sigma_E$。
- 实现奇偶函数：函数为变量的奇偶性时，直接用 280 的一个输出；未用的输入接地（0 不改变 1 的个数的奇偶性）。

## 9. 芯片选用要点

- 先确定函数的变量数与形式：
  - 单输出、变量不多：优先用 151 或 153（降维法）。
  - 多输出的译码（如存储器选片）：用 138 或 139。
  - 比较、加法、校验：用 85、283、280。
- 有效电平是最常见的接线错误：使能端、选通端、译码输出都要对照手册逐一确认。
- 芯片的功能表以手册为准。本文的表格用于讲解原理。

## 10. 讲解要点（给助教）

- 138 实现函数时，先让学生写出最小项与低有效输出的对应关系，再接与非门。
- 151/153 降维时，先列出降维表（选择码 × 数据端取值），再接线。
- 283 的 BCD 修正是课堂难点，建议先用表格列出 0～19 的和，再讲修正信号。
- 有效电平讲一次，后面反复提醒。
