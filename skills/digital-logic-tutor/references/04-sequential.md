# 第 3 章 时序逻辑（参考）

> 助教查阅用。时序电路的输出不仅取决于当前输入，还取决于电路原来的状态。
> 触发器特性表、激励表、状态表、状态图、计数器的反馈状态与序列、移位寄存器的状态序列，都必须调用 `dlogic_seq` 计算，正文只引用结果。
> 集成芯片的引脚名称按教材常用写法给出，有效电平与引脚编号以所用手册为准。

## 1. 锁存器

锁存器是电平敏感的存储单元：输入有效期间，输出随之变化；输入撤销后，输出保持。

### 1.1 基本 SR 锁存器（或非门）

由两个或非门交叉耦合，输入 $S$、$R$ 高电平有效。

- 特性方程：$Q^{n+1} = S + \overline{R}\,Q^n$，约束条件 $SR = 0$。
- 功能：$S=0,R=0$ 保持；$S=0,R=1$ 置 0；$S=1,R=0$ 置 1；$S=R=1$ 时 $Q=\overline{Q}=0$，属禁止状态，撤销后状态不定。

### 1.2 基本 SR 锁存器（与非门）

由两个与非门交叉耦合，输入 $\overline{S}$、$\overline{R}$ 低电平有效。

- 特性方程：$Q^{n+1} = \overline{\overline{S}} + \overline{R}\,Q^n$，约束条件 $\overline{S} + \overline{R} = 1$（两输入不能同时为 0）。
- 功能：$\overline{S}=0$ 置 1；$\overline{R}=0$ 置 0；$\overline{S}=\overline{R}=1$ 保持；$\overline{S}=\overline{R}=0$ 为禁止状态。
- 注意与或非门的区别：有效电平为低。画图与写激励时不要混用。

### 1.3 门控锁存器

在基本锁存器前加一级门，由时钟 $CP$ 控制是否接收输入。

- 门控 SR 锁存器：$CP=0$ 保持；$CP=1$ 时按 SR 功能，约束条件 $SR=0$。
- 门控 D 锁存器：$CP=0$ 保持；$CP=1$ 时 $Q^{n+1} = D$。
- **空翻**：在 $CP=1$ 期间，输入的多次变化都会反映到输出上，输出可能在一个脉冲内多次翻转。这是电平触发的固有特点，需要用边沿触发器避免。

## 2. 触发器

触发器只在时钟的有效边沿（上升沿或下降沿）接收输入，在其余时间保持。教材以上升沿触发为例。

### 2.1 特性方程与特性表

| 类型 | 特性方程 | 约束 / 说明 |
|---|---|---|
| SR | $Q^{n+1} = S + \overline{R}\,Q^n$ | $SR = 0$ |
| D | $Q^{n+1} = D$ | 无 |
| JK | $Q^{n+1} = J\overline{Q}^n + \overline{K}\,Q^n$ | 无 |
| T | $Q^{n+1} = T \oplus Q^n = T\overline{Q}^n + \overline{T}\,Q^n$ | 无 |

JK 触发器的特性表（$Q^n$ 为现态，$Q^{n+1}$ 为次态）：

| $J$ | $K$ | $Q^{n+1}$ | 功能 |
|---|---|---|---|
| 0 | 0 | $Q^n$ | 保持 |
| 0 | 1 | 0 | 置 0 |
| 1 | 0 | 1 | 置 1 |
| 1 | 1 | $\overline{Q}^n$ | 翻转 |

### 2.2 激励表

激励表与特性表相反：给出 $Q^n \to Q^{n+1}$ 的转换，求各输入应取的值。无关项记为 $\times$（或 X），表示该输入取 0 或 1 均可。

| 转换 | SR | D | JK | T |
|---|---|---|---|---|
| $0 \to 0$ | $S=0,\ R=\times$ | $D=0$ | $J=0,\ K=\times$ | $T=0$ |
| $0 \to 1$ | $S=1,\ R=0$ | $D=1$ | $J=1,\ K=\times$ | $T=1$ |
| $1 \to 0$ | $S=0,\ R=1$ | $D=0$ | $J=\times,\ K=1$ | $T=1$ |
| $1 \to 1$ | $S=\times,\ R=0$ | $D=1$ | $J=\times,\ K=0$ | $T=0$ |

- 激励表用于设计：由各触发器要求的 $Q^n \to Q^{n+1}$ 得到各输入的驱动方程。
- 无关项在化简驱动方程时按 1 或 0 处理，使表达式最简；工具 `dlogic_seq`（`op = ff`）直接给出激励表。

### 2.3 常见转换

- 把 JK 触发器接成 T 触发器：令 $J=K=T$。
- 把 JK 触发器接成 D 触发器：令 $J=D$，$K=\overline{D}$。
- 把 D 触发器接成 T 触发器：令 $D = T \oplus Q^n$。

## 3. 寄存器与移位寄存器

### 3.1 寄存器

由若干触发器并列组成，在同一时钟下同时存入一组数据，用于暂存。

### 3.2 移位寄存器（以 194 为例）

74LS194 是四位双向通用移位寄存器，常用引脚：$\overline{CR}$（异步清零，低电平有效）、$S_1$、$S_0$（工作方式选择）、$D_{SR}$（右移串行输入）、$D_{SL}$（左移串行输入）、$D_0 \sim D_3$（并行输入）、$CP$（上升沿有效）、$Q_0 \sim Q_3$。

| $\overline{CR}$ | $S_1$ $S_0$ | 功能 |
|---|---|---|
| 0 | × × | 异步清零，$Q_3 \sim Q_0 = 0000$ |
| 1 | 0 0 | 保持 |
| 1 | 0 1 | 右移：$Q_3 \leftarrow D_{SR}$，$Q_i \leftarrow Q_{i+1}$ |
| 1 | 1 0 | 左移：$Q_0 \leftarrow D_{SL}$，$Q_i \leftarrow Q_{i-1}$ |
| 1 | 1 1 | 并行置数：$Q_i \leftarrow D_i$ |

- 用 194 做序列信号发生或串并转换时，串行输入与时钟一一对应，每个时钟移一位。
- 状态字符串按 $Q_3Q_2Q_1Q_0$ 书写，左边为最高位。
- **方向约定**：不同教材对 $Q_A \sim Q_D$ 的位序写法不同，移位方向以题目给出的定义为准。`dlogic_seq` 的 194 约定为：右移时串行输入进入 $Q_3$（$Q_i \leftarrow Q_{i+1}$），左移时进入 $Q_0$（$Q_i \leftarrow Q_{i-1}$）。与题目不一致时，先在答案中说明位序，再计算。

## 4. 环形计数器与扭环计数器

这两类计数器由移位寄存器加反馈构成，结构简单，但有效状态与无效循环需要检查。

### 4.1 环形计数器

- 驱动：$Q_0 \leftarrow Q_{n-1}$，其余位依次右移。
- 模 $= n$。初态一般取一个 1 其余为 0（如 0001）。
- 有效循环有 $n$ 个状态；其余 $2^n - n$ 个状态组成若干无效循环（例如全 0 自循环）。

### 4.2 扭环计数器（约翰逊计数器）

- 驱动：$Q_0 \leftarrow \overline{Q_{n-1}}$，其余位依次右移。
- 模 $= 2n$。初态全 0。
- 有效状态中相邻两个状态只有一位不同。

以三位扭环计数器（模 6）为例，有效循环为 $000 \to 001 \to 011 \to 111 \to 110 \to 100 \to 000$。无效状态 $010$ 与 $101$ 组成一个二态循环，不能进入有效循环，因此**不能自启动**。需要修改反馈逻辑，使无效状态进入有效循环，并重新检查。

### 4.3 自启动检查

1. 从每一个无效状态出发，逐拍写出次态；
2. 若最终能进入有效循环，则能自启动；若陷入无效循环，则不能自启动；
3. 不能自启动时，修改驱动方程（改写无效状态的次态），再用 `dlogic_seq`（`op = analyze`）复核。

## 5. 集成计数器 160、161、163

### 5.1 共同引脚与功能

- $CP$：计数脉冲，上升沿有效。
- $\overline{CR}$：清零。161、160 为异步清零（$\overline{CR}=0$ 立即清零，与时钟无关）；163 为同步清零（$\overline{CR}=0$ 在下一个时钟上升沿清零）。
- $\overline{LD}$：置数，三片型号均为同步置数（$\overline{LD}=0$ 在时钟上升沿置入 $D_3 \sim D_0$）。
- $EP$、$ET$：计数使能，$EP \cdot ET = 1$ 时计数；$ET$ 同时控制进位输出 $RCO$。
- $RCO$：进位输出，$ET=1$ 且计数到最大状态时为 1，用于级联。

| 型号 | 进制 | 清零方式 |
|---|---|---|
| 160 | 十进制（8421 码） | 异步 |
| 161 | 四位二进制 | 异步 |
| 163 | 四位二进制 | 同步 |

### 5.2 清零法（反馈清零）

把某个状态译码后接到 $\overline{CR}$，使计数器跳过该状态。

- **异步清零（160、161）**：译码的状态 $N$ 一出现就立即清零，于是状态 $N$ 只短暂存在，称为**过渡态**。过渡态持续时间很短，可能在输出端产生毛刺。因此不能用来驱动对毛刺敏感的电路。
- **同步清零（163）**：当计数到 $N-1$ 时译码，下一个时钟沿清零，电路不经过状态 $N$，没有过渡态。

例：161 设计模 10 计数器，计数到 $1010$ 时清零，$\overline{CR} = \overline{Q_3 Q_1}$。状态 $1010$ 为过渡态。

### 5.3 置数法（反馈置数）

预置一个初值，计数到某个状态时通过 $\overline{LD}$ 重新置数。同步置数没有过渡态。

- 预置数：二进制芯片取 $D = 2^n - N$（161、163 取 $D = 16 - N$），十进制芯片取 $D = 10 - N$。
- 译码状态：通常取计数的最后一个状态（161、163 为 $1111$，160 为 $1001$）。
- 例：161 设计模 6 计数器，$D = 16 - 6 = 10$（$1010$），计数到 $1111$ 时 $\overline{LD} = \overline{Q_3 Q_2 Q_1 Q_0}$，状态序列为 $1010 \to 1011 \to 1100 \to 1101 \to 1110 \to 1111 \to 1010$。

### 5.4 两片级联

- 同步级联：两片共用 $CP$；低位片的 $RCO$ 接高位片的 $EP$、$ET$。
- 模 $N$ 大于一片的模时（如 161 计 100），用两片级联，反馈信号同时作用于两片。160 两片级联的最大模为 100，161、163 为 256。

工具 `dlogic_seq`（`op = counter`）给出反馈状态、状态序列与过渡态，并标出两片级联。

## 6. 同步时序电路分析

### 6.1 分析步骤

1. **写驱动方程**：各触发器输入端的逻辑表达式，变量为现态 $Q$ 与外部输入 $X$。
2. **求状态方程**：把驱动方程代入触发器特性方程，得到 $Q^{n+1}$ 的表达式。
3. **列状态表**：对每个现态与每种输入组合，求次态与输出。
4. **画状态图**：圆圈表示状态，箭头表示转换，箭头上标出输入/输出。
5. **说明功能**：模数、有效循环、计数方向，或输出与输入的关系（Moore 型输出只取决于现态，Mealy 型还取决于输入）。
6. **检查自启动**：无效状态是否都能进入有效循环（见 4.3）。

### 6.2 分析要点

- 状态表中的每一行都要写完整，不能遗漏无效状态。
- 有效状态组成的循环即为电路的正常工作序列。
- 禁止状态（使触发器输入违反约束的组合）要单独注明，不得直接当作有效状态。

工具 `dlogic_seq`（`op = analyze`）输入驱动方程与输出表达式，给出状态方程、状态表、状态图（节点与边）、有效循环、自启动结果与无效状态的流向。最多 4 个触发器、2 个外部输入。

### 6.3 异步电路

各触发器由不同信号触发（例如以前级输出作为时钟）时，每个时钟沿都要单独判断哪些触发器动作，分析步骤需要逐级展开。`dlogic_seq` 目前只分析同步电路，遇到异步电路时会在 warnings 中说明不支持，应在答案中明确说明这一限制并手工分析。

## 7. 同步时序电路设计（概要）

设计步骤：

1. **逻辑抽象**：确定输入、输出与状态的含义，画原始状态图或状态表。
2. **状态化简**：合并等价状态，减少状态数（不完全给定的状态表还需做相容类分析）。
3. **状态编码**：为每个状态分配二进制代码。
4. **选择触发器**：确定触发器类型与个数（状态数为 $N$ 时至少需要 $\lceil \log_2 N \rceil$ 个触发器）。
5. **求驱动方程**：由现态、次态与所选触发器的激励表得到各输入的表达式，无效状态对应的无关项要利用。
6. **检查自启动**，画逻辑图。

### 7.1 状态编码的相邻原则

- 若两个现态在同一输入下的次态相同，则它们的编码应尽量相邻（只差一位）。
- 若两个状态互为次态（相邻的转换），也应使编码相邻。
- 相邻编码可以使驱动方程最简，但不一定使电路最简，最终以工具计算的结果为准。

具体的编码评分与驱动方程生成由 `dlogic_fsm` 完成（状态化简、编码与自启动修正）。

## 8. 讲解要点

- 讲触发器时，先强调边沿触发与电平触发的区别，再讲特性方程。
- 讲激励表时，强调无关项 $\times$ 的含义，并说明它在设计中的用途。
- 讲计数器时，先区分清零法与置数法，再区分异步与同步两种清零方式，最后说明过渡态与毛刺。
- 讲自启动时，给出一个不能自启动的例子，并说明如何修正。
